(6) 429 → one retry after ≥2s recorded delay; second 429 → rate_limited, no fault, never a different model. (7) Report row (report_version 1): scenario name, tool, status (passed|failed|rate_limited|invalid_output), per-check outcomes with ERR_* code ONLY on agent faults (omitted otherwise), bounds+values, model id verbatim incl :free, rep index 0-based per cell, n>=3 reps default.
