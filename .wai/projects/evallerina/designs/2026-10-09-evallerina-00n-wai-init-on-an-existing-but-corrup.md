evallerina-00n: wai init on an existing-but-corrupt .wai/config.toml exits 0 with ok:true already_initialized:true and repairs nothing — a hint-blind agent believes it fixed the project. Decision: re-init must attempt ProjectConfig::load BEFORE emitting the ok envelope; if the config exists but fails to parse, init fails with an error envelope whose remediation hints 'wai doctor' (repair is doctor's channel; init must never silently overwrite a parseable-but-unwanted config — anti-goal). Non-JSON mode gets the same failure as a plain error. This keeps the hint-adherence eval honest: the blind replay (init green → stop) stays a detected fault because real init now fails.
